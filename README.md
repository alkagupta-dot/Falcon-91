# FALCON 91 Static Website

English-language static site based on the business details supplied in the Udyam Registration Certificate.

## Files
- `index.html` — Home
- `about.html` — About the business
- `services.html` — Independent digital business guidance
- `dashboard.html` — Public business details
- `contact.html` — Contact details and mailto enquiry form
- `faq.html` — Frequently asked questions
- `privacy.html` — Privacy policy template
- `terms.html` — Terms of use template
- `css/style.css` — Responsive styling
- `js/script.js` — Mobile navigation and email form

## Run
Open `index.html` in your browser. No Node.js or build process is required.

## Publish on GitHub Pages
1. Create a repository and upload all files and folders from this ZIP.
2. In repository Settings → Pages, enable GitHub Pages for your chosen branch and root folder.
3. Add your custom domain in Pages settings. Configure DNS exactly as GitHub Pages instructs, then enable HTTPS when available.

## Before publishing
- Confirm all business/contact information is correct and suitable for public display.
- This site intentionally leaves out social-category information that is not needed for a public business profile.
- The contact form opens the visitor's email application; no message is stored or sent by the website server.
- Adapt the privacy policy and terms to your actual practices.
- This is an independent business website. It does not impersonate Meta or claim official affiliation; no verification outcome is guaranteed.
